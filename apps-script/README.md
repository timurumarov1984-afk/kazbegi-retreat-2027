# Приёмник заявок: чтобы заявки не терялись

Без приёмника сайт отправляет анкету прямо в Google-форму. Узнать, приняла ли её форма, сайт не может, поэтому показывает «Спасибо» в любом случае. Если в форме кто-то поменял вопрос или вариант ответа, Google молча отклонит заявку, и её никто не увидит.

Приёмник — это маленький скрипт Google. Он работает на почте ретрита и с каждой заявкой делает три вещи:

1. передаёт её в форму и проверяет, что ответ правда появился в таблице;
2. сохраняет копию в отдельный лист «Заявки с сайта», даже если форма ответ не приняла;
3. присылает письмо с заявкой на почту ретрита. Если форма ответ не приняла, письмо приходит с пометкой ⚠.

«Спасибо» человек видит только тогда, когда заявка сохранена. Ещё приёмник каждый день сверяет вопросы формы с анкетой на сайте и пишет на почту, если они разошлись.

## Установка (10 минут, один раз на ретрит)

Всё делается под почтой ретрита (например, kazbegi.retreat@gmail.com). Форма должна принадлежать этой почте или быть открыта ей на редактирование.

1. Откройте https://script.google.com и нажмите «Новый проект». Назовите его, например, «Заявки Казбеги 2027».
2. Удалите всё, что есть в редакторе, и вставьте содержимое файла `Code.gs` из этой папки.
3. Заполните `CONFIG` в начале файла:
   - `FORM_EDIT_URL` — адрес формы в режиме редактирования (тот, что в строке браузера, заканчивается на `/edit`);
   - `NOTIFY_EMAIL` — куда присылать заявки;
   - `SITE_URL` — адрес сайта ретрита со слешем в конце;
   - `RETREAT` — название для темы писем.
4. Сохраните проект (значок дискеты).
5. Сверху выберите функцию `setup` и нажмите «Выполнить». Google попросит разрешения: «Проверить разрешения» → выберите почту ретрита → «Дополнительно» → «Перейти к проекту» → «Разрешить». На почту придёт письмо «Приёмник заявок подключён».
6. «Начать развёртывание» → «Новое развёртывание».
   - Тип (значок шестерёнки): «Веб-приложение».
   - «Запуск от имени»: «От моего имени».
   - «У кого есть доступ»: «Все».
   - Нажмите «Начать развёртывание» и скопируйте адрес веб-приложения (`https://script.google.com/macros/s/…/exec`).
7. На GitHub откройте `_data/retreat.yml` и вставьте этот адрес в `form.endpoint:` в кавычках. Сохраните (Commit changes). Через минуту сайт обновится.

## Проверка после установки и после каждой правки формы или анкеты

1. Отправьте тестовую заявку с сайта. В имени напишите «ТЕСТ».
2. Проверьте, что:
   - на сайте появилось «Спасибо, заявка получена!»;
   - в таблице ответов формы есть новая строка;
   - в листе «Заявки с сайта» есть строка с «да» в колонке «В форме»;
   - на почту пришло письмо без пометки ⚠.
3. Удалите тестовую строку из таблицы.

## Если вы поменяли код Code.gs

«Начать развёртывание» → «Управление развёртываниями» → карандаш → «Версия: новая» → «Начать развёртывание». Адрес приёмника не изменится.
