# Сайт ретрита с Мастером · Казбеги 2027

Это первый сайт на общем шаблоне ретритов. Дизайн и блоки у всех ретритов общие. Всё, что отличает один ретрит от другого, хранится в одном файле **`_data/retreat.yml`** и в папке с фото **`assets/img/`**.

Сайт собирает сам GitHub Pages: ничего устанавливать не нужно. После правки сайт обновляется примерно через минуту.

## Как поправить текст, дату или цену

1. На GitHub откройте `_data/retreat.yml` и нажмите карандаш (Edit).
2. Найдите нужное место. Разделы в файле идут в том же порядке, что блоки на сайте, и у каждого есть подсказка.
3. Внизу нажмите «Commit changes».
4. Через минуту обновите страницу сайта.

Если в файле ошибка (например, пропущена кавычка), GitHub не обновит сайт. Останется прошлая версия, а на почту владельца репозитория придёт письмо «Page build failed». Тогда откройте последнюю правку и проверьте отступы и кавычки рядом с ней.

Правила записи:
- `ru:` — русский текст, `en:` — английский. Если английского нет, показывается русский.
- `*слово*` в заголовке — выделение цветом.
- Даты пишутся как `"2027-07-12"`. Даты словами на всех страницах («12–19 июля 2027») сайт пишет сам.
- В текстах можно ставить подстановки: `{dates}`, `{start}`, `{checkin}`, `{checkout}`, `{intensive_dates}`, `{private}`, `{email}`, `{telegram}`, `{rules}`. Тогда дата или цена меняется в одном месте, а не в двадцати.
- Неразрывные пробелы после коротких слов («в&nbsp;горах») сайт ставит сам.

## Как устроен сайт

- **Главная — коротко о главном:** ретрит и интенсив, «Как это было», что включено, расписание, место (кратко), стоимость и кнопки глав. Какие блоки показывать и в каком порядке — список `home.blocks` в `retreat.yml`.
- **Главы — отдельные страницы:** «Интенсив», «Проживание» (номера, бронь, атмосфера отеля), «Досуг» (активности и сотворчество), «Как попасть», «Как добраться», «Частые вопросы». Список и карточки глав — раздел `chapters`. Удалите строку — пропадут кнопка, пункт меню и карточка.
- **Ретрит и интенсив — два полноценных события.** На первом экране стоят две карточки с датами, у интенсива своя страница, своя цена в «Стоимости» и отдельное событие для поисковиков.
- **«Только вживую, без онлайн-трансляции»** написано на первом экране, в «О ретрите», в стоимости, на странице интенсива и в частых вопросах. Тексты — `retreat.live`.

## Что включается и выключается

| Что | Где в `retreat.yml` | Как |
|---|---|---|
| Интенсив после ретрита | `intensive:` | Удалите весь раздел (и строку `intensive` в `chapters`) — не будет страницы, карточки на первом экране, цены и дат в расписании |
| Бронь номеров | `rooms.mode` | `through_us` — бронируют организаторы (шаги брони, итог за весь срок); `hotel_site` — человек бронирует сам на сайте отеля (`rooms.hotel_site.url`, промокод) |
| Ранние цены | `pricing.tiers` | Ступени «при оплате до (`until`) — цена», у последней можно `from` («с 01.04.2027»). Текущая ступень подсвечивается сама, прошедшие зачёркиваются, за 60 дней до повышения появляется «До повышения цены — N дней». Пустой список — одна цена из `pricing.parts`. Под ценой — список `pricing.includes` («Входит в стоимость») |
| Цена интенсива | `pricing.intensive.prices` | Одна или несколько цен с подписью («Участникам ретрита — 400 €», «Только интенсив — 550 €») |
| Расписание интенсива | `intensive.days` | Дни интенсива с часами — отдельный блок в расписании и на странице интенсива, свой выезд `intensive.checkout` |
| Где жить | `rooms.options` | Три варианта (в Rooms через нас, в Rooms самостоятельно, в другом месте) — на странице «Проживание» и на странице интенсива |
| Номера и цены | `rooms.categories` | У каждой категории варианты (`variants`: вид, кровать) с ценой для одного и двоих без НДС; цены с НДС (`rooms.vat`) и итог за официальные ночи сайт считает сам; `url` — ссылка «Номер на сайте отеля» |
| Лента фото | `strip` | 4–8 фото места с подписями (на главной после расписания). Вертикальные 3:4; у широкого 16:9 — `wide: true`, оно займёт две колонки |
| Карточки практик | `included.cards` | Список ключей из каталога `practices:` (yoga, breathwork, massage…). Порядок в списке — порядок на сайте. Описание ведущего (`lead`) раскрывается по нажатию. Если подходящего фото нет, вместо `photo` поставьте иллюстрацию: `art: { name: yoga, ka: "იოგა", note: { ru: "…", en: "…" } }`. Готовые иллюстрации: `yoga`, `breath`, `massage`, `bbq` (`_includes/art.html`) |
| «Как это было» | `memories:` | 5 фото. `video:` — файл в `assets/video/`, тогда появится кнопка «Смотреть видео». Без раздела блока нет |
| Видео на первом экране | `retreat.hero.video` | Уберите «#» у строки `video:` и положите файлы в `assets/video/` — вместо фото будет видео (как в DOMA) |
| Сайт о методе Мастера | `site.method_url` | Пусто — ссылок нет нигде |
| Скрыть от поисковиков | `site.draft: true` | На время согласования страницы (например, с отелем) |
| Статистика | `site.analytics.goatcounter` | Имя счётчика GoatCounter. Он не ставит cookie, поэтому баннер согласия не нужен |

## Характер места

У каждого ретрита общие структура и блоки, а **характер места** свой. У Казбеги он собран из трёх частей:

- **Казбек.**
  - Логотип — силуэт Казбека.
  - Внизу «Расписания» идёт линия горы, обведённая по фото заката из Степанцминды, с церковью Гергети и подписями «Казбек · 5 054 м · მყინვარწვერი» и «Гергети · 2 170 м».
  - На круге у фото отеля — грузинское имя Казбека.
- **Грузинская графика, совсем немного.**
  - Борджгали — грузинский знак солнца — в центре вращающегося круга.
  - Плетёнка, как в резьбе по камню, — между блоками «О ретрите» и «Как это было» и в подвале.
  - Бледное слово ყაზბეგი («Казбеги») за заголовком «Место».
- **Дерево и лофт, как в самом отеле.**
  - Светлые блоки стали светлым дубом с еле заметными волокнами.
  - Вместо арок фото стоят в стальных рамах окон. У фото отеля есть переплёт, как в лаунже с видом на Казбек.

Где что лежит:
- тексты (подписи, грузинские слова) — в `_data/retreat.yml`, раздел `identity`;
- графика — в `_includes/identity/`;
- стили — в `assets/css/identity.css`.

Грузинский шрифт (Noto Serif Georgian) загружается только для тех букв, что есть на сайте, поэтому весит несколько килобайт. Если удалить раздел `identity`, сайт станет нейтральным, на общем стиле. У другого ретрита (например, DOMA) свой `identity.css` и свои файлы в `_includes/identity/`, и он не трогает сайт Казбеги.

## Фото

Фото лежат в `assets/img/` (WebP, ширина 1200–1920 px). Чтобы заменить фото, загрузите файл с тем же именем или впишите в `retreat.yml` новое имя. Если на фото важна одна часть, например лицо, укажите `pos: "50% 30%"`: эта точка останется в кадре при обрезке.

Каждое фото должно показывать то, о чём блок. Если для карточки нет снимка по теме, лучше поставить иллюстрацию (`art`), чем случайный кадр.

## Анкета и заявки

- Вопросы анкеты находятся в `retreat.yml`, раздел `form.steps`. Каждый вопрос связан с вопросом Google-формы номером `entry`.
- Варианты ответов (`v:`) должны совпадать с формой слово в слово, иначе Google не примет заявку.
- **Перед публикацией и после любой правки формы** проверьте, что анкета совпадает с формой:
  ```
  node tools/check-form.mjs https://адрес-сайта/apply.html
  ```
  Скрипт ничего не отправляет. Он показывает, какой вопрос не совпал и почему.
- **Без приёмника анкета заявки не отправляет** и «Спасибо» не показывает: человек видит ошибку и запасные пути (почта, Telegram, Google-форма). Это сделано нарочно — чтобы не было ложного «заявка получена».
- **Чтобы заявки не терялись**, установите приёмник на почте ретрита (`apps-script/README.md`, 10 минут) и впишите его адрес в `form.endpoint`. Тогда:
  - сайт показывает «Спасибо» только после настоящего подтверждения;
  - копия каждой заявки сохраняется в таблицу;
  - на почту ретрита приходит письмо с заявкой;
  - раз в день идёт сверка анкеты с формой.
- Вопросы «В чём будешь участвовать?» (ретрит / ретрит и интенсив / только интенсив) и «Какая категория номера?» уже есть в анкете, но скрыты, пока у них пустой `entry`. Добавьте их в Google-форму 2027 с теми же вариантами и впишите номера — вопросы появятся на сайте.

## Чек-лист перед публикацией

- [ ] Даты, цены и ступени ранних цен сверены с организаторами.
- [ ] `node tools/check-form.mjs …/apply.html` выдаёт «✓ Анкета совпадает с формой».
- [ ] Тестовая заявка (имя «ТЕСТ») появилась:
  - строкой в таблице ответов;
  - в листе «Заявки с сайта» с «да»;
  - письмом на почте ретрита.
- [ ] Статистика видит заход (если подключена).
- [ ] Ссылка на правила (`site.rules_url`) открывает документ только для чтения: в конце адреса `/preview`, у документа доступ «Читатель».
- [ ] `site.url` заполнен — без этого в Telegram и WhatsApp не будет картинки в превью ссылки.
- [ ] `site.draft: false`, когда страница согласована и её можно показывать всем.
- [ ] На телефоне (390 px) нет горизонтальной прокрутки, первый экран читается.

## Как устроен шаблон (для того, кто меняет дизайн)

```
_data/retreat.yml       — содержание этого ретрита (единственное, что правят организаторы)
_layouts/default.html   — каркас страницы: шапка, меню, подвал, метатеги, превью ссылки
_includes/blocks/       — блоки главной страницы (hero, about, memories, included, schedule, intensive,
                          place, stay, activities, cocreate, pricing, guide, final)
_includes/*.html        — общие части: шапка, меню, подвал, карточки, даты словами, двуязычный текст
_includes/identity/     — характер места этого ретрита: логотип, линия Казбека, плетёнка, грузинское слово
index.html, intensive.html, stay.html, leisure.html, join.html, travel.html, faq.html, apply.html — страницы: только список блоков
assets/css, assets/js   — оформление и поведение (язык, анимации, ранние цены, лайтбокс, анкета);
                          assets/css/identity.css — стили характера места
apps-script/            — приёмник заявок (Google Apps Script)
tools/check-form.mjs    — сверка анкеты с Google-формой
```

Дизайн и набор блоков меняются только в шаблоне и по договорённости, чтобы все сайты выглядели одинаково. Следующий шаг — вынести шаблон в отдельный репозиторий-тему. Тогда у каждого ретрита в репозитории останутся только `retreat.yml` и фото, а правки дизайна будут приходить во все сайты из одного места.

Посмотреть сайт у себя на компьютере (нужен Jekyll 3.10, как на GitHub Pages):

```
jekyll build && cd _site && python3 -m http.server 8777
```

## Публикация

Сайт опубликован на GitHub Pages: **https://timurumarov1984-afk.github.io/kazbegi-retreat-2027/**
(репозиторий `timurumarov1984-afk/kazbegi-retreat-2027`, ветка `main`). Сайт собирает сам GitHub, через 1–2 минуты после изменения.

Сейчас это **черновик для согласования** (с отелем и организаторами):
- `site.draft: true` — поисковики сайт не видят, в углу пометка «Черновик для согласования»;
- `form.enabled: false` — анкету можно посмотреть и заполнить, но заявки не отправляются.

Когда страница согласована: `site.draft: false`, `form.enabled: true`, приёмник заявок по `apps-script/README.md` и тестовая заявка по чек-листу выше.
