# Ретрит с Мастером Камильпашой в Казбеги · 1–18 июля 2027

Статический сайт на HTML, CSS и JS, собирать ничего не нужно. Чтобы посмотреть, откройте `index.html` в браузере.

Место — Rooms Hotel Kazbegi, Степанцминда, Грузия. Интенсив 19–21 июля стоит на сайте как предварительный.

Сайт собран на основе португальского (DOMA, ветка `main`). **Эту ветку нельзя сливать в `main`**: она заменяет португальский сайт.

## Структура

```
index.html              — главная страница (RU и EN тексты рядом)
join.html / travel.html / faq.html — «Как попасть на ретрит», «Как добраться», «Частые вопросы»
apply.html              — анкета участника (своя страница, ответы уходят в Google-форму)
assets/css/styles.css   — оформление сайта (цвета — в начале файла, :root)
assets/css/apply.css    — оформление анкеты
assets/js/main.js       — язык, меню, анимации, смена фото на первом экране, фото в лайтбоксе
assets/js/apply.js      — вопросы анкеты и отправка в Google-форму
assets/img/             — фото (WebP):
    hero-1…4            первый экран: лаунж с видом на Казбек → долина Степанцминды → терраса отеля → пастух в горах
                        (-m — вертикальные кадры для телефона)
    kz-*                мозаика «Горы, которые замедляют» (открывается крупно)
    остальные           фото отеля, номеров, активностей с сайтов Rooms Kazbegi и прошлого ретрита (Gamma)
```

## Как править тексты

Каждый текст записан дважды:

```html
<span lang="ru">Заполнить заявку</span><span lang="en">Fill in the application</span>
```

Меняйте оба варианта. Язык переключается кнопкой RU/EN, ссылка с `?lang=en` открывает английскую версию.

## Анкета

- Все кнопки «Заполнить заявку» ведут на `apply.html`. Анкета разбита на 4 шага, черновик сохраняется в браузере.
- Сейчас ответы уходят в прошлогоднюю Google-форму Казбеги («Анкета участия в ретрите 2026 с Мастером»).
  - В самой форме остались тексты 2026 года.
  - Вопрос «все номера закончились» обязательный. Анкета отвечает на него сама, исходя из выбора «жить в Rooms».
- Вопросы описаны в `assets/js/apply.js` в массиве `STEPS`. Подписи (`ru`, `en`) можно менять свободно.
- Значения вариантов (`v`) должны совпадать с Google-формой слово в слово, иначе Google не примет ответ.
- Если в Google-форме добавить или удалить вопрос, нужно обновить `STEPS`: у нового вопроса будет новый номер `entry`.
- Если для 2027 года сделают новую форму, замените `FORM_ACTION`, `fbzx` и номера `entry`.
